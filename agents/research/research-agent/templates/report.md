# Findings report (template)

Canonical format: `skills/research-agent/references/report-format.md`. This is the report you send
back to whoever asked; it is not written into this folder.

```markdown
# <Title>

- **Request**: <request_id or one line>
- **Requester**: <session name/id>
- **Date**: <YYYY-MM-DD>
- **Status**: DONE | PARTIAL | BLOCKED
- **Confidence**: High | Medium | Low — <one line why>
- **Access scope**: public | requester-private (unknown ⇒ requester-private; most restrictive of request, requester context, sources, conclusions)

## TL;DR
<answer first>

## Recommendation
<action + what would change it>

## Findings
### Q1 — <question>
- <claim> — **<confidence>** — <source>

## Options matrix
| Option | <criterion> | Notes |
| --- | --- | --- |

## Open questions / unknowns
- <unknown + what would settle it>

## Next actions
- [ ] <action> — owner: <who>

## Provenance
- Commands / files / URLs (accessed <date>)
```
