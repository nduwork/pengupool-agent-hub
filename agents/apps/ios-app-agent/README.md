# ios-skill

A task repo for one job: **Set up, sign and ship an iOS app to TestFlight and the App Store, and manage its keys, certificates and secrets**

An agent session started here loads `skills/ios-shipping/SKILL.md`, follows `AGENTS.md`, and keeps its owner's
standing rules in PenguPool memory.

| Path | Purpose |
| --- | --- |
| `AGENTS.md` | always-on rules for any agent here |
| `skills/ios-shipping/SKILL.md` | how to do the task |
